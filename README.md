# AIVEX

```bash
> ai desktop assistant
> tauri • electron • backend • ai
```

AIVEX is a desktop AI assistant focused on productivity, modern UI and local-first experience.

- AI assistant interface
- desktop application
- local-first architecture
- release management
- backend integration
- screen capture
- audio support
